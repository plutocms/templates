Welcome to your blog. Each post is a **Markdown file** in the `content/posts`
folder of your GitHub repository.

## Write in the admin

Open `/admin`, sign in with GitHub, and create a post. Each save is a commit,
so the history of every post is in git.

- Drafts stay hidden on the site.
- Publish when the post is ready.
